## Como rodar localmente

- JDK 17+
- IntelliJ IDEA (ou `mvn spring-boot:run`)
- Acesso ao Oracle da FIAP (`oracle.fiap.com.br:1521`)

```
git clone git@github.com:MatheusC0625/Sprint4Java.git
cd Sprint4Java
mvn spring-boot:run
```

A aplicação sobe em `http://localhost:8080`.
